🧪 Software Registry Editor

Desktop wallpaper changes take effect immediately after saving.

🎨 System theme (WG_color)

Use b for the dark theme or w for the light theme. The desktop and Start menu update immediately after saving.

🖼️ Desktop wallpaper (WG_desktop_wallpaper)

Enter a single wallpaper path or separate multiple paths with commas, for example: ./wallpaper/a.jpg, ./wallpaper/b.jpg. Multiple wallpapers rotate at the selected interval; a single wallpaper does not rotate. The default interval is 60 seconds. Changes take effect immediately after saving.

📱 Custom app list (app_list)

Format: [{"id":"test","name":"Example","icon":"icon.png","path":"test.html"}]

📌 Start menu pinned apps (fixedApps)

Format: ["doc","setting"]

📎 Taskbar pinned apps (fixedTaskbarApps)

Format: ["wgver","setting"]. Only app IDs are stored.

🖥️ Desktop icons (desktopIcons)

Format: ["doc","setting"]
